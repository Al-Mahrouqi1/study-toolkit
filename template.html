Builds on What a database is→Leads to ER diagrams

Everything in this chapter is built from three ideas; get these right and the diagrams make sense.

كل ما في الفصل مبني على ثلاث أفكار؛ افهمها وستفهم المخططات.

Entity

Slide 4
الكيان: الشيء الذي نحفظ عنه بيانات، مثل الطالب.
Definition
A thing or object in the real world that is distinguishable from all other objects.
In plain words
Something we want to keep data about.
How it works
  • Each entity becomes a table.
  • Each real item is one row (an instance).
Example
Student, Course, Department.
Common mistake
Calling a property like Name an entity; Name describes something, it is an attribute.
Connects to
  • Attribute — an entity is described by its attributes

Attribute

Slide 5
الخاصية: تفصيلة تصف الكيان، مثل اسم الطالب.
Definition
A property that describes an entity.
In plain words
A detail about the thing.
How it works
  • Becomes a column in the entity's table.
  • One attribute (the key) identifies each row.
Example
StudentID, Name, Major.
Common mistake
Forgetting the key attribute that makes each row unique.
Connects to
  • Entity — every attribute belongs to one entity
Entity vs attribute
EntityAttribute
Isa thinga detail of the thing
Becomesa tablea column
ExampleStudentName
Key points · أهم النقاط
  1. An entity is a thing; an attribute describes it.
  2. Entity → table, attribute → column.
  3. Every entity needs a key attribute.

3Sample formula (CPU time)مثال معادلة (زمن المعالج)

Slides 10–12 · الشرائح 10–12

Law · CPU execution timeالقانون · زمن تنفيذ المعالج
CPU time = IC × CPIf
SymbolMeaning · المعنىUnit
ICInstruction countعدد التعليمات
CPICycles per instructionعدد الدورات لكل تعليمةcycles
fClock rateتردد الساعةHz

When to use: To compare how long a program takes on a processor.

متى نستخدمه: لمعرفة الزمن الذي يستغرقه برنامج على معالج.

Watch out: Convert GHz to Hz (× 109) before dividing.

انتبه: حوّل GHz إلى Hz (× 109) قبل القسمة.

Worked example مثال محلول Slide 11

A program runs 2 × 109 instructions with CPI = 1.5 on a 3 GHz processor. Find the CPU time.

برنامج ينفّذ 2 × 109 تعليمة بمتوسط CPI = 1.5 على معالج 3 GHz. أوجد زمن التنفيذ.

Given
  • IC = 2 × 109
  • CPI = 1.5
  • f = 3 GHz = 3 × 109 Hz
Find

CPU time

  1. CPU time = IC × CPIf
    Write the law.
    نكتب القانون.
  2. CPU time = 2 × 109 × 1.53 × 109
    Substitute the values with units in Hz.
    نعوّض بالقيم مع تحويل التردد إلى Hz.
  3. CPU time = 3 × 1093 × 109
    Multiply the numerator: 2 × 1.5 = 3.
    نضرب البسط: 2 × 1.5 = 3.
  4. CPU time = 1 s
    Divide.
    نقسم.
Answer · الإجابةCPU time = 1 sone second
Check · تحققCycles = 3 × 109 ; time = cyclesf = 1 ssame result using clock cycles
